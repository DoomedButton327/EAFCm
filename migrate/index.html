Migration Tool v2

Convert your old league-data.json into the new conflict-safe file structure — one file per game, one file per player.

What This Tool Does
New structure is conflict-safe for bulk GitHub pushes. Each game gets its own unique file (with an 8-char random ID), so multiple pushes at the same time can never collide or overwrite each other.
NEW STRUCTURE data/ ├── player-data.json ← primary player stats (JSON) ├── index.json ← list of all game file paths ├── players/ ← one .txt file per player │ ├── tyronb.txt │ └── player2.txt └── games/ ← one .txt file per game └── 2026-04-19/ ├── tyronb_vs_player2_a3f9c1d2.txt └── player3_vs_player4_bb12ef44.txt
The tool reads your old league-data.json and outputs a single mettlestate-migration.zip with the correct folder structure ready to push to GitHub.

Step 4 — Deploy to GitHub
1
Extract the ZIP

Extract mettlestate-migration.zip — you'll see a data/ folder with the full structure.

2
Push to your GitHub repo

Drag the data/ folder into your repo via the GitHub web UI, or use git add data/ && git commit && git push. All files are independent so there's no push conflict.

3
Load from GitHub in the dashboard

Go to Admin → GitHub Sync → click Load from GitHub. Your players, results, and fixtures will all load from the new structure.

4
Remove the old league-data.json

Once everything looks correct, delete the old file from your repo. It's no longer used.
