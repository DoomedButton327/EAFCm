Migration Tool

Convert your old league-data.json to the new date-partitioned folder structure.

What This Tool Does
Converts the old single-file format into the new split structure:
data/player-data.json — all player records
data/index.json — index of all match days
data/YYYY-MM/YYYY-MM-DD/match-day.json — fixtures + results per day
NEW STRUCTURE data/ ├── player-data.json ← all players ├── index.json ← match day index └── 2026-04/ ├── 2026-04-15/ │ ├── match-day.json ← fixtures + results │ └── match-images/ └── 2026-04-20/ └── match-day.json

Step 2 — Options
Fixtures without a scheduledDate will be assigned today's date.
Step 3 — Convert & Download

The tool will generate all required JSON files as a ZIP download. Extract it into your GitHub repo root.

Step 4 — Deploy to GitHub
1
Extract the downloaded ZIP

Extract mettlestate-migration.zip — you'll see a data/ folder.

2
Commit to your GitHub repo root

Drag the data/ folder into your repo via the GitHub web UI, or push via git.

3
Open the dashboard and click "Load from GitHub"

In Admin → GitHub Sync, click Load. Your data will populate from the new structure.

4
Delete the old league-data.json

Once confirmed working, remove the old file from your repo.
